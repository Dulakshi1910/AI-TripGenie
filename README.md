🌍 AI TripGenie – AI-Powered Travel Planning Web App

AI TripGenie is a full-stack web application that helps users plan trips efficiently using AI-assisted features. The platform focuses on secure authentication and smart checklist management to enhance the travel planning experience.

✨ Key Features

Google OAuth2 Authentication for secure login

AI-assisted travel checklist generation based on trip details

Full CRUD operations for checklist management

Real-time checklist progress tracking

Scalable architecture for future AI trip planning features
